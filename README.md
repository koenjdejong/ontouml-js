# OntoUML JS (OpenAPI Transformation)

This repository is a fork of [OntoUML-JS](https://github.com/OntoUML/ontouml-js)

## Fork Extension: OpenAPI Transformation

This repository is a proof of concept of a transformation from OntoUML to OpenAPI. 
I created this while working on my Bachelor Thesis (Technical Computer Science) at the University of Twente. 
The paper is available [in this repository](resources/Transformation%20from%20OntoUML%20models%20to%20the%20OpenAPI%20Specification.pdf).
